# 📚 IAASB Documentation Archive

A centralized collection of PDF documents sourced from the **International Auditing and Assurance Standards Board (IAASB)** website.

This repository brings IAASB publications and historical documentation into one convenient location so they can be **downloaded, searched, analyzed, archived, referenced, and used for research or other legitimate purposes**.

## 🔗 Source

The original documents are associated with the official IAASB website:

- **IAASB:** https://www.iaasb.org/

This repository is an independent collection and is **not affiliated with or endorsed by the IAASB**.

## 📦 What's Included?

The [`PDFs/`](PDFs/) directory contains collected IAASB publications, including historical handbook volumes and other IAASB documentation.

Examples include:

- 📘 IAASB Handbooks
- 📑 IAASB standards and publications
- 📚 Historical editions and handbook volumes
- 🔍 Audit-quality documentation
- 📖 Technical and professional guidance
- 🗂️ Other publicly available IAASB PDF documentation

The collection is intended to make these documents easier to work with from a single repository.

## 🚀 Why Is This Useful?

Having the documents in a GitHub repository provides several practical advantages.

### 🔎 1. Easy Access

Instead of repeatedly navigating through the IAASB website to locate individual publications, you can access the collected documents from one place.

You can browse, download, clone, or search the repository whenever you need a document.

### 💻 2. Offline Access

Once the repository has been cloned, the PDFs are available locally.

```bash
git clone https://github.com/PrajwalKoirala638/iaasb-org-documentation.git
```

This makes the collection useful when internet access is unavailable or when you want to work with the documents locally.
